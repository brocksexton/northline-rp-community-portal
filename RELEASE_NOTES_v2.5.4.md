# Northline RP Community Portal v2.5.4

## Tweeter polish pass

### Changed
- Removed the large `View Steam Profile` button from Tweeter profile headers when the smaller Steam link/profile summary link is already available.
- Hid duplicate left-rail navigation and right-rail search when Retro or Classic uses the legacy top navbar.
- Reworked the legacy navbar Tweet button so it reads as a polished disabled action instead of a mismatched default button.
- Widened and cleaned up the Classic right rail so `Who to follow` has more breathing room.
- Improved Retro and Classic layout spacing so the theme differences are clearer.
- Added hover finishing touches to tweet cards and Steam/profile links.

### Notes
- Web posting is still intentionally unavailable. The Tweet button remains disabled until a safe game bridge exists.
- The package excludes generated artifacts such as `.next`, `node_modules`, `package-lock.json`, and TypeScript build info.
