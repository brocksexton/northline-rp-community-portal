# Northline RP Community Portal v2.9.12

## Tweeter claimed-profile visibility

- Steam website sign-ins now claim a lightweight public community profile record without overwriting existing profile settings.
- Tweeter `Who to follow` suggestions now only include citizens who have claimed a website profile and kept it public.
- Tweeter profiles remain accessible for citizens who have posted, even when they have not claimed a website profile yet.
- Unclaimed Tweeter profiles now show a dedicated notice explaining that posts and follows remain available while DMs and custom profile details are limited.
- Follow actions no longer require the target citizen to have a claimed website profile or recorded server join date; only the viewer must meet the current social-action requirements.
- Website DMs now stay locked when the target citizen has not claimed a website profile yet.
