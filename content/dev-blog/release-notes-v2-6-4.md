# Northline RP Community Portal v2.6.4

## Homepage readability hotfix

This build keeps the community-first homepage direction from v2.6.3, but fixes the low-contrast dark treatment.

### Changed
- Homepage now defaults to a bright, readable community style.
- Text contrast improved across hero copy, cards, stat tiles, death report, Tweeter preview, and noticeboard.
- Header/nav contrast improved while viewing the community homepage.
- Website style variants still apply:
  - Civic Clean: bright community portal.
  - Northline Glass: soft blue glass style.
  - Control Center: still dark, but now high-contrast and readable.

### Untouched
- Tweeter pages/components and Tweeter theme CSS were not changed.
