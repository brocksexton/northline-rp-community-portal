# Northline RP Community Portal v2.6.5

## Rules handbook overhaul

This release rebuilds `/rules` into a more approachable Northline citizen handbook.

### Added
- Playful rules hero and quick five-minute rule pass.
- Quick-start rule cards for new players.
- Expandable rulebook sections using native `<details>` interactions.
- Scenario lab cards that reveal better roleplay choices.
- Consequence/severity roadmap.
- Staff report checklist.
- Final “would this make a good story?” callout.

### Notes
- Tweeter files were not modified.
- This keeps the rules practical and community-oriented rather than corporate/legalistic.
