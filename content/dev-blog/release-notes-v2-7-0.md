# Northline RP Community Portal v2.7.0

## Unified profile direction

- `/u/[steamId]` now redirects to `/tweeter/profile/[steamId]`, making Tweeter-style profiles the main user profile experience.
- Player directory cards now open Tweeter profiles directly.
- Removed the older public-profile presentation from the main route instead of continuing to polish two competing profile designs.

## Title cleanup

- Added shared resource-title formatting.
- In-game title resource IDs such as `resources.titles.the_saver` now display as `The Saver`.
- Applied title formatting to public profile data, Tweeter profile data, player directory search data, and dashboard character cards.

Tweeter styling itself was not restyled in this pass.
