# Northline RP Community Portal v2.7.1

## Guides Hub

This release rebuilds `/guides` into a more useful player-facing handbook.

### Added
- New Northline Field Guide homepage for `/guides`.
- Beginner-friendly first-night path.
- Quick links to Dashboard, Citizens, Status, Support, Rules, and Tweeter.
- “What are you trying to do?” guide cards.
- Expandable handbook sections for:
  - first session onboarding
  - better roleplay scenes
  - making money
  - property/building basics
  - reports and staff interactions
  - profiles and Tweeter identity
- Quick-answer FAQ cards.
- Do / Don’t roleplay cards.
- Cleaner in-game guide catalog display with signed-in progress.

### Notes
- Tweeter was not modified in this pass.
- The guide content is intentionally written for end users, not as development notes.
- Package version bumped to `2.7.1`.
