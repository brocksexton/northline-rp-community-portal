# Northline RP Community Portal v2.8.0

## Tweeter profile repair

- Repaired Tweeter profile action styling so `Edit profile` and `Follow` render as proper pill controls instead of plain text.
- Tightened the profile hero stack so avatar, banner, actions, copy, meta, and tabs align more predictably across dark, light, and blue Tweeter modes.

- Improved profile summary wrapping for long Steam IDs.

## Northbound RP game-image covers

- Replaced the old gradient/icon cover presets with Northbound RP gameplay image presets sourced from the provided sbox CDN image links.
- Updated profile settings copy to describe game-image banner presets.
- Allowed trusted/staff custom cover URLs from `cdn.sbox.game/upload/i/...` even when the CDN URL does not include a traditional file extension.
