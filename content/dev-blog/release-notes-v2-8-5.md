# Northline RP Community Portal v2.8.5

## Tweeter profile polish

- Tightened the Tweeter profile header spacing so the avatar, name, handle, bio, and actions feel more naturally grouped.
- Replaced the larger always-open citizen sidebar card with a compact profile action card and a collapsible details menu.
- Removed the nested right-rail scrollbar on Tweeter profile pages.

## Players page

- Player directory cards now use each public profile's selected cover image instead of only a color gradient.

## Homepage / footer

- Improved Ape Tavern banner contrast so the copy stays readable against the dark background.
- Rebuilt the main website footer with a warmer community style, quick links, Discord/Northbound RP links, and the NorthlineRP wordmark treatment.
