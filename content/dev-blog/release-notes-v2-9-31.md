# Northline RP Community Portal v2.9.31

## Dev Blog polish

- Reworked Dev Blog cards and detail pages for clearer contrast in both light and dark mode.
- Removed the overly dark, low-contrast card treatment that made release notes hard to read.
- Public Dev Blog copy is less technical and no longer calls out the content folder path in the toolbar.
- Dates now include real date and time values instead of version-spaced placeholder dates.
- Dev Blog loading falls back to each markdown file's filesystem modified time when a post does not provide a date.
