# Northline RP Community Portal v2.9.4

## Homepage polish

- Improved the homepage shortcut hub for readability and a cleaner feel.
- Reworded several homepage cards to sound less corporate and less awkward.
- Cleaned up the Ape Tavern banner by removing the extra pill tags and small appreciation footer line.
- Kept the Northbound RP Discord button and guide button.

## Maintenance mode options

- Added an option to keep Tweeter available while the main website is in maintenance mode.
- Added a separate Tweeter maintenance toggle so Tweeter can be paused without closing the rest of the site.
- Added custom Tweeter maintenance headline, message, and optional countdown.
- Added a Tweeter-styled maintenance page.
- Removed the extra developer explanation text from the maintenance page.
- Improved maintenance page message contrast.

## Notes

- Tweeter pages still work normally unless Tweeter-specific maintenance is enabled.
- Maintenance settings continue to save to `.northline-data/site-maintenance.json` or `NORTHLINE_DATA_PATH/site-maintenance.json`.
