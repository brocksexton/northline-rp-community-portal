# Leaderboards

Northline leaderboards are generated from the server export files and the website profile store.

## Privacy rules

Leaderboards are intentionally opt-in:

- A player must have a claimed public website profile.
- Private profiles are hidden from every board.
- Boards that use optional profile sections only include users sharing that section:
  - Economy boards require the Economy showcase.
  - Stats boards require the Stats showcase.
  - Inventory boards require the Inventory showcase.
  - Property boards require the Properties showcase.
  - Activity boards require the Activity showcase.

Tweeter boards use public Tweeter activity attached to public profiles.

## Included boards

- Net worth
- Wallet cash
- Bank balance
- Time in city
- Highest level
- Total XP
- Items held
- Saved layouts
- Saved props
- Tweeter posts
- Tweeter likes earned
- Fatal accidents
- Combat tags
- Guide progress

The JSON version is available at `/api/leaderboards`.
