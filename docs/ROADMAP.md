# Northline RP Portal Roadmap

## Phase 1 — Foundation

- Keep the portal read-heavy and file-safe.
- Finalize Northline branding, copy, and navigation.
- Validate `APE_RP_DATA_PATH`, `SITE_URL`, and `SESSION_SECRET` before production use.
- Keep Steam OpenID and profile settings stable.

## Phase 2 — Player Experience

- Expand dashboard widgets based on real save data.
- Add profile showcase controls.
- Add guide-specific pages and richer onboarding copy.
- Add optional public profile sections per privacy category.

## Phase 3 — Community Experience

- Improve Tweeter search, tags, replies, and author pages.
- Add events and scheduled maintenance pages.
- Add appeal/ticket information.
- Add public city statistics with metagame-safe aggregation.

## Phase 4 — Staff Experience

- Add player lookup and filters.
- Add evidence-bundle export for appeals.
- Add status notice editing UI.
- Add audit logs for all website-owned staff actions.

## Phase 5 — Game Bridge

- Create a signed bridge between website and s&box.
- Queue actions instead of directly editing game files.
- Start with low-risk actions: web Tweeter post requests, staff notices mirrored in-game, notification preferences.
- Add rate limits, audit logs, and rollback paths.

## Phase 6 — Supporter Expansion

- Add supporter entitlement storage without checkout first.
- Add cosmetic-only badges/themes/showcase slots.
- Publish a no-pay-to-win donation policy.
- Add payments only after moderation, refund, tax, and terms policies are ready.
