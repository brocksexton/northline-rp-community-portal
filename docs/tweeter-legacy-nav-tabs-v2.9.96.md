# Tweeter legacy navigation and tabs polish — v2.9.96

This pass adjusts the Mid-2010s and Classic Tweeter layouts after visual review.

## Changes

- Increased the horizontal legacy navbar height, link size, icon size, and spacing.
- Enlarged the legacy search and Tweet controls so the navbar no longer feels compressed.
- Reworked the Mid-2010s timeline tab strip into a clean three-way segmented row for For you, Latest, and Bookmarks.
- Added clearer active/hover states for Mid-2010s tabs.
- Tuned Classic tabs to stay compact but readable and evenly split.

These changes are CSS-only and are intentionally scoped to Tweeter legacy era layouts.
