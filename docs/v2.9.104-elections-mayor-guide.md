# Northline RP v2.9.104 - Elections & Mayor Guide

## Included
- Added a new visual guide for Elections & Mayor with real in-game screenshots.
- Added multi-image slide support in the guide modal so some steps can show several screenshots together.
- Simplified the Guides landing page so it feels lighter for new players.
- Updated the mayor card to focus on starting elections, registering as a candidate, voting, campaigning, and using the Mayor computer.

## Notes
- Elections begin with Michael at the Police Department.
- Starting an election does not automatically register the player as a candidate.
- Mayor policy changes are handled from the top floor computer and shown in the Government app.
