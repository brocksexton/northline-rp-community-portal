# v2.9.106 build memory hardening

This patch targets a production build failure during Next.js static page generation on lower-memory Windows servers.

## Changes
- `npm run build` now runs Next through Node with a larger heap:
  - `node --max-old-space-size=4096 node_modules/next/dist/bin/next build`
- Next build concurrency is reduced in `next.config.mjs`:
  - one build CPU
  - worker threads disabled
  - static generation concurrency reduced
  - static generation timeout raised

## Why
The previous build compiled and typechecked successfully, then failed during static page generation with:

`FATAL ERROR: Zone Allocation failed - process out of memory`

That points to build-time memory pressure rather than a TypeScript or application code error.

## Deployment note
If the server still has issues, close other heavy processes during rebuild or increase the Windows page file. The web app code itself was not failing typecheck in the reported log.
