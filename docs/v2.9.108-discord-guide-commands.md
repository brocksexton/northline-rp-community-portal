# v2.9.108 — Discord bot guide commands

## Added commands
- `/job police` — Police Officer / Chief of Police guide
- `/job chief` — same guide as police, for Chief of Police lookups
- `/job mayor` — Elections & Mayor guide
- `/job courier` — Courier delivery guide
- `/job medic` — Medic guide
- `/job business` — Store Owner / Business guide
- `/job citizen` — Citizen starter guide
- `/guide topic:<topic>` — general guide picker with all current guides
- `/northline guides` — guide hub embed

## Clean-up
- Updated `/northline help` to include guide commands.
- Added the Guides link to `/northline links`.
- Guide embeds include a synopsis, covered topics, shortcut command, and direct website link.
- `/guides?guide=<id>` now opens the matching guide modal directly on the website.

## Deployment note
After updating the bot code, run:

```bash
npm run bot:register
```

Then restart the bot process so the new command handlers are live.
