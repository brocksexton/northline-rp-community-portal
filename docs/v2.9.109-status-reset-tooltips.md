# v2.9.109 — Status reset and graph tooltips

## Staff status reset
- Added a staff-only reset action on `/staff/status` for clearing stale public connected-user/status roster data.
- The reset writes `status_runtime_reset.json` into the configured `APE_RP_DATA_PATH`.
- Public status, `/api/status`, and the navbar ignore connection-log events older than the latest reset marker.
- Server start, kill, and restart actions from the web control panel now also try to reset the public status snapshot automatically.

## Graph hover detail
- Population trend points on `/status` now expose detailed hover titles.
- Staff metric history graph points now expose detailed hover titles for timestamp and value.

This is intended to prevent stale players from being shown after restarts or missing disconnect events.
