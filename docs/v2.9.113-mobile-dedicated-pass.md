# v2.9.113 — mobile dedicated pass

This pass intentionally keeps desktop layouts untouched by scoping layout changes to phone-sized media queries.

## Included
- Added an explicit viewport export with safe-area support.
- Improved mobile header/menu sizing and touch targets.
- Added mobile-only one-column layouts for major page shells and cards.
- Improved mobile hero typography and action button stacking.
- Improved mobile behavior for Status, Guides, Rules, Support, Players, Forum, Staff, Dashboard, Legal, Jobs, and Tweeter surfaces.
- Made charts, tables, pre/code blocks, and dense data panels scroll safely on small screens.
- Improved guide modal sizing, image stacking, progress controls, and safe-area spacing on phones.
- Improved Tweeter mobile profile/feed readability without affecting desktop Tweeter layouts.
