# v2.9.114 — Discord embed refresh

## What changed
- Removed the automatic global banner image from every bot embed so commands no longer all show the same photo.
- Added per-guide images and thumbnails using existing Northline guide assets.
- Improved guide embeds with:
  - clearer synopsis text
  - “what it covers” bullets
  - “good for” usage context
  - direct website link
  - Discord link button
  - themed colours per guide
- Improved `/northline guides` with a stronger guide hub embed and an Open guide hub button.
- Added better embed footer branding with the local Northline/Ape Tavern icon.
- Status, player, death, and fun embeds now use lighter visual treatment instead of forcing the same large image everywhere.

## Notes
`NORTHLINE_BOT_BANNER_URL` is no longer applied globally to every bot embed. Specific embeds now choose images only when they are actually useful.
