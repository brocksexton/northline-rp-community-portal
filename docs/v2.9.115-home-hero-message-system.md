# v2.9.115 homepage hero message system

## Added
- Configurable homepage hero messages stored in `.northline-data/home-hero-messages.json` or `NORTHLINE_DATA_PATH/home-hero-messages.json`.
- Multiple default messages per time of day so the homepage does not repeat one line for hours.
- Random eligible message selection on dynamic homepage render.
- A public "New vibe" action on the homepage that reloads the hero with another eligible message.
- Staff site-settings editor for homepage hero messages.

## Staff controls
Staff with website configuration access can manage messages at `/staff/site`:
- add messages
- duplicate messages
- delete messages
- enable/disable messages
- edit label, greeting, title, body, scene note, icon, and visual tone
- choose one or more time windows: any time, late night, morning, afternoon, evening, winter, Halloween, or new year

## Notes
Signed-in titles can use `{name}` where the player's display name should appear.
