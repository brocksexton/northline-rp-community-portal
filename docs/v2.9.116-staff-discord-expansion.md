# v2.9.116 — Staff Discord page expansion

Expanded `/staff/discord` into a fuller Discord operations page.

## Added
- New Discord Operations hero copy.
- Five-section staff panel:
  - Overview
  - Guide Embeds
  - Message Builder
  - Command Book
  - Roles + Users
- Guide embed launcher for common player help topics.
- Quick-send and load-in-builder actions for guide cards.
- Asset picker for existing guide screenshots.
- Command reference with copy-to-clipboard shortcuts.
- Setup/health checklist and clearer Discord API status information.
- Better channel and role summaries.
- Relative website image/link paths in Discord panels now normalize to absolute public URLs before being sent to Discord.

## Notes
The existing Discord bot commands still need to be registered with `npm run bot:register` after deployment if command definitions changed separately. This update mainly improves the staff website UI and embed workflow.
