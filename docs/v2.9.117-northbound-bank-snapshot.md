# v2.9.117 - Northbound Bank snapshot

Added a first-pass private Northbound Bank page at `/bank` using the data currently available in the game export.

## What it shows now
- Current bank balance
- Current wallet cash
- Liquid funds
- Estimated net worth when item/container values are available
- Inventory, hotbar, equipment, and mailbox storage usage
- Top held items
- Container cash detected in nested item data
- Saved property layout counts
- Economy-related tracked stats
- A statement-style snapshot that clearly explains it is not a full transaction ledger yet

## Navigation
- Added Northbound Bank to the signed-in account menu
- Added a bank card and quick action to the Profile Studio dashboard

## Limitations
The current game data does not contain a true transaction ledger. This page does not invent purchase history; it only presents balances and storage records that exist in the save data.
