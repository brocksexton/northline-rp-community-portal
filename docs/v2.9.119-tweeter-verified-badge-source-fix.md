# v2.9.119 — Tweeter verified badge source fix

## Fixed
- Tweeter timeline cards no longer trust stale `VerifiedKind` values exported with individual in-game tweets.
- Timeline, tweet detail, suggestions, and profile headers now resolve verification from the same source of truth:
  - Ape Tavern badge list
  - current website/staff role
  - otherwise no verified badge

## Why
A user could appear verified in the Tweeter feed while their profile correctly showed no badge because old tweet metadata still contained a `VerifiedKind` value. The feed now ignores that stale per-tweet value.
