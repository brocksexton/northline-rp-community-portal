# v2.9.120 — Discord bot branding icon fix

## What changed
- Removed the Ape Tavern logo from the bot's default Discord embed branding.
- Added a dedicated Northline bot icon at `/northline-bot-icon.png`.
- Updated all default bot embed thumbnails/footers that were still hard-coded to the old Ape Tavern asset.
- Added a safeguard so old `NORTHLINE_BOT_ICON_URL` values pointing at `apetavern-logo.png` automatically fall back to the new Northline icon.

## Why
Northline RP is not Ape Tavern, so the bot should not visually brand server notifications with Ape Tavern artwork.
