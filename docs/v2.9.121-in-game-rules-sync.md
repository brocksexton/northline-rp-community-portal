# v2.9.121 — in-game rule sync

## What changed
- Added a canonical short rule list at `config/server-rules.json`.
- Updated `/rules` so the website shows the exact short rules intended for the in-game pause menu and spawn rule display.
- Updated the detailed rulebook to reflect the recent Northbound RP changes:
  - in-game rules support
  - warrants for property raids
  - ATM robberies
  - Mayor custom laws, tax rate, contraband, and illegal buildables
  - illegal buildables / contraband risk
  - AFK/inactive job removal
  - stronger exploit wording for shops, crates, payouts, and buildables
- Added a sync command for your live server data directory:

```bash
NORTHLINE_DATA_PATH="C:\\Servers\\northline-data" npm run rules:sync
```

or:

```bash
node scripts/sync-server-rules.mjs "C:\\Servers\\northline-data"
```

This updates `server_config.json` by replacing only the `ServerRules` array.

## Database note
The uploaded data directory does not include an obvious database connection config or migration setting. It does contain `DbId` fields in property layouts, but that appears to be internal object identity/state and not enough to configure database support. Database setup should wait until the game/mod documentation or generated config exposes the expected provider/connection fields.
